# Age Calculator

An interactive Age Calculator built with HTML, CSS, and JavaScript. The application calculates a user's age based on their date of birth.

## Features

- **Date of Birth Input:** Allows users to select their birth date using a date picker.
- **Age Calculation:** Calculates the user's age based on their date of birth.
- **Accurate Birthday Check:** Checks whether the user's birthday has passed in the current year.
- **Future Date Validation:** Prevents users from selecting a future date.
- **Input Validation:** Displays a message when no date is selected.
- **Dynamic Results:** Displays the calculated age without reloading the page.
- **User-Friendly Interface:** Simple and clean design.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

- `index.html` – Application structure.
- `style.css` – Application styling.
- `script.js` – Age calculation and validation functionality.

## How to Use

1. Open the Age Calculator.
2. Select your date of birth.
3. Click the Calculate Age button.
4. Your calculated age will appear on the screen.

## How It Works

The application uses JavaScript's Date object to obtain the user's birth date and the current date.

It calculates the difference between the current year and birth year, then checks whether the birthday has occurred this year.

If the birthday has not yet occurred, the calculated age is reduced by one.
